# 什么样的场景可以做

只去有真手艺活的经营场所。判断一个场景能不能做，看的是员工手上的活，而不是店的类型。

这里说的**场景**，是指一类工作环境和工作内容，比如汽车维修、手机维修、服装裁缝、中餐后厨、设备调试。数据量、额度和要准备多少，都按场景来算。

## 金标准：三条，越符合越好 {#gold-standard}

| 标准 | 怎么判断 |
|---|---|
| 熟练度 | 新人要练得越久才能上手，越好 |
| 工序 | 一件活包含的步骤越多，越好 |
| 工具和工况 | 用到的工具越多、现场情况变化越多，越好 |

拿不准的场景，就按这三条对一遍。三条都弱的，不要谈。

### 正反例

| 标准 | 正面：维修（汽修、家电、手机） | 反面：电子厂打螺丝 |
|---|---|---|
| 熟练度 | 要几年才能独立排查故障 | 半天就能上手 |
| 工序 | 检查、判断、拆、换件、装回、测试 | 拿件、对位、拧紧，一直重复 |
| 工具和工况 | 万用表、扳手、焊枪轮流用，每台机器毛病都不一样 | 一把电批，每个件都一样 |

## 适合去谈的场景

下面是一些通常符合金标准的方向，供找场景时参考。最终能不能做，以试录结果为准。

| 方向 | 例子 | 要找的岗位 |
|---|---|---|
| 维修 | 汽修厂、家电维修、手机维修、自行车 / 电动车维修、钟表维修 | 师傅、技师 |
| 制作加工 | 裁缝、改衣、皮具、鞋匠、木工、金属加工、焊接 | 做活的师傅 |
| 餐饮后厨 | 中餐馆后厨、面点、烘焙 | 厨师、面点师、烘焙师 |
| 个人服务 | 理发、美甲、配镜 | 发型师、美甲师、验光配镜师 |
| 建筑装修 | 水电、瓷砖、木作、油漆 | 施工师傅 |
| 工厂 | 有设备的工厂 | 调机、修设备、返修、质检，**不是流水线工位** |

## 不收的活

- **简单重复的活：** 上架、补货、分拣、搬运、打包、贴标、导购
- **家务类的活：** 清洁、擦拭、洗衣、叠衣叠被、收拾，就算在店里做也不收
- **工厂流水线上的重复工序：** 基本不算数

### 这些也不算技能 {#not-skills}

| 情况 | 为什么不算 |
|---|---|
| 焊工扫地 | 看的是活，不是人的身份。扫地还是扫地 |
| 分装小螺丝 | 东西小不代表难，还是分拣 |
| 端热锅 | 有危险不代表有技能，还是搬运 |
| 码两小时箱子 | 又累又久，还是码箱子 |
| 用五种工具拆快递 | 工具多、步骤多，还是拆快递 |
| 打包中间焊了 5 秒 | 太短，不到 30 秒不算 |

## 场所本身的要求

- **必须是真实的经营场所，不在家里录。** 靠它谋生的家庭作坊可以，户外作业也可以
- **操作员必须是真正做这份工作的员工**，不能临时找人来演
- **员工多、手艺活种类多的店，能做得更久**
- **多开几个场景，比在一个场景里一直录更有价值**

### 每个场地能贡献的时长有上限 {#site-cap}

上限按门店规模算：

| 规模 | 员工人数 | 单个场地上限 |
|---|---|---|
| 小 | 15 人以下 | 500 小时 |
| 中 | 15–100 人 | 2,000 小时 |
| 大 | 100 人以上 | 5,000 小时 |

中型和大型场地必须能提供营业执照等企业信息。

## 新场景先试录 {#trial}

1. **已经在采的场景：** 谈好就可以直接铺设备
2. **新场景：** 先拿一台设备试录 2 小时，上传后等验收结果
3. **试录通过：** 再大规模铺开

试录不通过，对接人会告诉你原因。有时候换一个岗位就能通过。

## 要准备多少场景 {#how-many}

同一个场景、同一个买家能收的数据量有上限。越简单的场景，录得越多越容易饱和，饱和后再录就不算有效时长。所以手上的场景越多，设备越能持续轮换，不会闲着。

### 怎么估算

```
每月需要的场景数 ≈ 设备每月总录制时长 ÷ 单个场景能收的时长
```

- **设备每月总录制时长**：每台设备每周一般录 30–45 小时，按设备台数乘一下
- **单个场景能收的时长**：由买家需求决定，不同场景差别很大。复杂场景能收得多，简单场景很快就满。各类场景当前的额度，问对接人

### 实际操作上

- **复杂场景优先**，能做得更久；简单场景作为补充，轮换着用
- **同一个场地可以有多个场景**：一家综合维修店可能同时有手机维修、家电维修、电动车维修
- **连锁品牌的每家分店**都是独立的场地，可以一家一家铺
- **持续开新场景**，不要等饱和通知来了才去找
