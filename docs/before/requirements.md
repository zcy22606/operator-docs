# 要求、收益与注意事项

## 谁适合做运营方

主要是两类人：

- **手上有工厂和商业场景资源的人。** 认识很多工厂、维修店、加工作坊、餐馆的老板，能直接带设备进场
- **有很强地推、直销或电销经验的人。** 能快速陌拜、谈下大量门店，并且持续开新店

不需要懂技术。会用手机 App、会在电脑上拷文件就够了。

## 基本要求

| 要求 | 说明 |
|---|---|
| 签约主体 | 能以公司或个体工商户的名义签合同、收款 |
| 场景资源 | 签约前手上要有能落地的场景，数量见 [要准备多少场景](/before/scenes#how-many) |
| 现场管理 | 有人能每天跑店：培训操作员、检查设备、处理现场问题 |
| 上传条件 | 一台电脑（Mac、Linux 或 Windows 10/11），足够的硬盘空间，以及**每台设备至少 3 MB/s 的上传带宽**。见 [上传带宽](/after/upload#bandwidth) |
| 响应速度 | 收到验收反馈或轮换通知后，当天或第二天就能安排 |

## 能得到什么

- **按有效时长结算的收入。** 数据通过验收就结算，具体方法见 [收入怎么算](/before/payment)
- **设备由 OpenRoboto 提供。** 运营方不用买设备（以协议为准）
- **充电宝和 SD 卡可以报销。** 读卡器、硬盘等其他配件由运营方自己负责
- **完整的流程和工具。** 场景判断、设备配置、上传、验收都有现成的方法，对接人全程支持
- **推荐收益。** 介绍新的运营方进来，可以参加 [推荐计划](/business/referral)
- **门店也有收益。** 门店和员工可以从中拿到报酬，谈合作时更容易开口

## 要注意的事

### 质量决定收入

只有通过验收的时长才算钱。录得多不等于赚得多，录得对才行。被判不合格的数据要重采；**连续两次不合格，采集可能被全部暂停**。

### 这几条红线不能碰

| 红线 | 后果 |
|---|---|
| 画面里有人着装不合规 | 立即停录。被检测到裸露 3 次，合作终止 |
| 找人来演、安排假活 | 数据作废 |

### 同一个场景、同一个买家有上限

同一个场景、同一个买家能收的数据量有上限，录满了再录就不算有效时长。越简单的场景，饱和得越快。所以要准备尽可能多的场景，让设备不断轮换和铺开，不能只守着一两个场景。详见 [额度与轮换](/after/daily-operations#rotation)。

### 设备要保管好

设备交到你手上后由你负责保管。丢失、损坏的处理方式写在协议里，收设备时要签 [设备交接单](/business/templates/device-handover)。

### 前期要投入

开头几周要花时间谈店、培训、调设备，收入会慢慢上来。建议先从两三个场景开始，跑顺了再扩。
