# 收入怎么算

这一页只讲计算方法。单价、激励金额和结算周期以你和 OpenRoboto 签署的协议为准。

## 基本公式

```
当期结算金额 = 当期有效时长 × 协议单价 ＋ 激励（如协议中有约定）
```

### 有效时长怎么来

- 运营方上传的是全部录制，但只有经 GI Labs 验收、认定为可用的部分才算**有效时长**
- 整个工作时段一直开着录，验收时只挑出 **30 秒以上、围绕同一个结果的技能片段**计入。中间的简单活不算钱，也不扣分
- 同一个场景、同一个买家能收的数据量有上限，超出部分不计入
- 每个场地有总时长上限，见 [场地上限](/before/scenes#site-cap)
- 有效时长以 GI Labs 的验收报告为准，OpenRoboto 按报告结算

### 有效率

```
有效率 = 有效时长 ÷ 上传总时长
```

有效率是衡量一个运营方做得好不好的最直接的指标。验收报告里会写清楚每段无效的原因，照着改，有效率就会上来。

## 激励

如果协议里有激励条款，一般从下面几个方面考核。具体金额以协议为准。

| 维度 | 看什么 | 怎么算 |
|---|---|---|
| 跑满 | 设备有没有闲着 | 有效时长 ÷ 设备理论产能（设备台数 × 约定的每月标准工作时长） |
| 跑好 | 数据能不能用 | 有效率 |
| 跑宽 | 场景够不够多样 | 当期有效的场景数。一个场景要达到最低有效时长才算 |
| 跑久 | 合作稳不稳定 | 连续合作的月数，交付量的波动大小 |

两条门槛：

- **有效率低于 50%，当期其他激励不发放**
- **每台设备平均每周有效时长低于 25 小时，不参与激励评定**

把一个场景拆成几个名字凑数、临时拉人凑数、月底突击，都不会被计入。

## 配件和成本

### OpenRoboto 报销

| 配件 | 说明 |
|---|---|
| 充电宝 | 每台设备 1 个 |
| SD 卡 | 每台设备 2 张 |

报销方式和额度以协议为准。

### 运营方自己负责

| 成本 | 说明 |
|---|---|
| 门店和员工报酬 | 给门店的合作费、给操作员的录制补贴，怎么给由你和门店商量 |
| 读卡器、硬盘 | 拷卡和存放用 |
| 人力 | 跑店、培训、上传的人工 |
| 网络和电脑 | 上传用的宽带、电脑 |
| 交通 | 跑店、换店的路费 |

### 给门店和员工的报酬怎么定 {#site-pay}

常见的做法有三种，可以组合使用：

| 方式 | 适合 | 注意 |
|---|---|---|
| 按有效时长分成 | 想让门店一起关心质量 | 要把验收结果同步给门店 |
| 按录制天数或时长给固定补贴 | 门店更看重稳定、简单 | 质量风险在你这边，要管好现场 |
| 一期一次性合作费 | 小店、合作期短 | 先约定好这一期录多久、覆盖哪些岗位 |

## 怎么提高收入

1. **先把有效率做上去。** 看每天的验收结果，按原因整改
2. **别让设备闲着。** 提前准备好下一个场景，轮换不要等
3. **多开场景。** 场景越多，越不容易饱和
4. **长期稳定地做。** 稳定交付的运营方更容易拿到更多设备
