# 异常处理

## 设备

| 情况 | 怎么办 |
|---|---|
| `Add device` 里找不到设备 | 确认设备已开机。用 USB 时，安卓要允许相机权限；用 Wi-Fi 时，手机和设备要在同一网络。从没配过 Wi-Fi 的设备，只会出现在 `Nearby setup hotspots` 里 |
| 设备提示没有 SD 卡 | 卡是开机后插的，重启设备。还不行，联系对接人 |
| 分辨率里没有 1728×1200 | 联系对接人，不要选相近的数值 |
| 改了分辨率没变化 | 要重启才生效 |
| 手部检测自己关掉 | 设备启动不了这个功能，检查固件并升级 |
| 录出来的日期是 1970 年 | 当天没连手机。以后每天开工先连一次 |
| 设备丢失或损坏 | 当天告诉对接人，按协议和交接单处理 |

## 扫码

| 情况 | 怎么办 |
|---|---|
| 提示 *This is not a Visio settings code* | 这张码不对，联系对接人重新生成 |
| 提示需要新版 App | 更新 Visio Companion |
| 确认页没有两个 ID 行 | App 太旧，更新后重扫 |
| 上传时每次都问"谁录的" | 编号没写进录制。重扫并看两个 ID 行；还不行就升级固件 |

## 上传

| 情况 | 怎么办 |
|---|---|
| 上传时问"哪天录的" | 设备当天没连手机，填真实日期 |
| 上传报错，但一部分传上去了 | 正常。补完没传的再重新上传，不删原文件 |
| 上传中断 | 重新运行同一条命令，已传的会跳过 |
| 文件挪到了另一个硬盘 | 用新路径重新运行，上传进度会保留 |
| 清理时有文件删不掉 | 后台还没确认收到，故意保留的，等确认后再清 |
| 上传太慢 | 看 [上传带宽](/after/upload#bandwidth)：每台设备至少 3 MB/s。必要时把卡集中到网络好的地方传 |

## 现场

| 情况 | 怎么办 |
|---|---|
| 现场有人着装不合规 | 立刻停止录制，当天告诉对接人 |
| 员工不愿意再戴 | 尊重本人意愿，换其他员工戴 |
| 门店临时不让录 | 先停，弄清原因，告诉对接人 |
| 收到换场景或挪设备的通知 | 尽快安排，换完记得重新扫码 |
| 验收报告里无效时长多 | 按 [常见的无效原因](/after/acceptance#invalid-reasons) 整改，拿不准的问对接人 |

## 联系对接人时带上这些

- 设备序列号（设备页 `Identity` → `Serial`）
- 固件版本（设备页 `Build`）
- 出问题的门店和操作员
- 用命令行上传的，先运行 `gi-ingest doctor`，把输出一起发过来
- 能截图的尽量截图
