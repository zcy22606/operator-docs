# 验收与结算

有效时长以 GI Labs 的验收结果为准，结算统一按验收结果。计算方法见 [收入怎么算](/before/payment)。

## 验收报告

- GI Labs 每天出验收报告，给出每段录制的有效小时数
- 对接人把结果同步给你，并告诉你哪些场景要换，哪些店要加或减设备
- 被判无效的原因会写在报告里，照着整改

## 常见的无效原因和改法 {#invalid-reasons}

| 原因 | 怎么改 |
|---|---|
| 手经常出画 | 调低镜头角度；提醒操作员手和工件保持在视线正前方；打开手部检测 |
| 活太简单 | 换岗位或换场景，见 [什么活算数](/after/daily-operations#what-counts) |
| 这个场景已饱和 | 换到其他场景 |
| 片段太短、太零碎 | 一直开着录，不要按工序开关 |
| 画面里有不合规着装 | 现场提醒，有人不合规立刻停录 |
| 摆拍、放慢动作 | 告诉操作员按平常的方式干 |
| 分辨率不对 | 检查是不是 1728×1200，重启后再确认 |
| 日期是 1970 年 | 每天开工先连手机 |

## 不合格的数据

- 被判不合格的数据要重采
- **连续两次不合格，GI Labs 可能暂停全部采集**

## 结算

- OpenRoboto 按验收报告和运营方结算
- 结算周期、对账方式和付款方式以协议为准
- 对验收结果有疑问，在协议约定的时间内提出，并附上录制编号和设备序列号

## 你要留存的记录 {#records}

| 记录 | 用途 |
|---|---|
| 每天的上传记录（`gi-ingest history` 或后台 `Deliveries`） | 对账 |
| 验收报告 | 对账、整改 |
| 员工同意书（如有签） | 备查 |
| 门店合作协议 | 合规备查 |
| 设备交接单 | 设备责任 |
| 你给门店和员工的付款记录 | 自己对账 |
