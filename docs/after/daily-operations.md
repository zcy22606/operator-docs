# 收到设备后：日常运营

## 每天的节奏

| 时间 | 谁 | 做什么 |
|---|---|---|
| 开工前 | 运营方 / 店里指定的人 | 设备开机、连手机校时、检查设置、扫码、戴好 |
| 工作时段 | 操作员 | 一直开着录，正常干活 |
| 收工 | 上传负责人 | 停录、换卡、拷卡、开始上传 |
| 第二天早上 | 上传负责人 | 确认后台收到，清理副本和 SD 卡 |
| 每天 | 运营方 | 看验收结果，按反馈整改，安排轮换 |

## 怎么录

整个工作时段一直开着录。验收时只挑出 30 秒以上、围绕同一个结果的技能片段算数。中间的简单活不算钱，也不扣分。

- **开工就开录**，正常干活，**不要按工序开开关关**，也不要挑着录
- **只有三种情况关机：** 休息超过 1 分钟；没活干；去厕所、更衣室等私密区域
- **换人、换店才停录**，换了要扫新码。顺序是：停止录制 → 扫新码 → 开始录制

## 基本规则（每段都要满足）

| 规则 | 要求 |
|---|---|
| 着装 | 画面里所有人至少：男性穿短裤或更长；女性上衣盖住胸和腰腹，加短裤、长裤或裙子。有人不合规就立刻停录。**被检测到裸露 3 次，合作终止** |
| 真活 | 本来就要干、靠它吃饭的活，不安排、不演 |
| 看得到进展 | 一段录完，手上的东西要变：切了、接上了、修好了、成形了。不重做做完的活 |
| 正常速度 | 不放慢、不夸张动作 |
| 不磨洋工 | 不录发呆、刷手机、假装干活。等胶干、检查结果、想下一步这种自然停顿可以 |
| 手在画面里 | 手、工具尖端、正在加工的东西几乎全程在画面里、看得清。连续 10 秒以上手出画的片段会被删 |
| 自己戴 | 头戴双目相机，顺着自然视线朝下。不用三脚架，不让别人拿着拍 |
| 隐私 | 收款码、手机号、支付信息尽量避开 |

## 什么活算数 {#what-counts}

### 基础技能

手上要有真功夫，一不小心就会做坏。每段至少体现一种：

| 类型 | 意思 | 例子 |
|---|---|---|
| 精准控制 | 稳住角度、线条、力度、张力或位置 | 在小触点上焊线、沿曲线缝边、穿球拍线、剃发际线 |
| 判断决策 | 看到信号、读数或瑕疵，据此决定下一步 | 测电路板后决定换哪个元件、检查焊缝后返工 |
| 装配调整 | 相互依赖的零件反复调，直到装好、能用 | 装刹车蹄和弹簧、量管切管装到位 |
| 过程控制 | 温度、时间、材料在变，人跟着调，出问题能救回来 | 焊接、颠锅炒菜、断纱后重新穿线 |

重复同一个技能动作可以（一针接一针），只要每一下都要用心；整段坐在一个工位也可以。

### 进阶工作

基础技能之上的一整套活，下面 7 条全满足：

1. 至少 3 个不同步骤，顺序有讲究（量 → 切 → 装 → 检查）
2. 用到不止一种技能
3. 不是一个动作贯穿全段
4. 因为活的需要在工作区走动、挪工件
5. 在经营场所，不在家里（家庭作坊除外）
6. 至少一次检查、测量或测试，并根据结果采取行动
7. 标准设备和标准设置

同一种活两档都可能：在工位上一根接一根焊线是基础技能；找出电路板故障、换件、再测试修好没有，就是进阶工作。

不算技能的情况，见 [这些也不算技能](/before/scenes#not-skills)。

## 怎么带操作员

第一次戴设备前，花 15 分钟讲清楚这几件事：

1. **为什么录：** 用来教机器人干活，所以要录真实的、正常速度的活
2. **怎么戴：** 头戴，镜头顺着视线朝下，手和工件要在画面里
3. **什么时候关：** 休息超过 1 分钟、没活、去私密区域
4. **着装：** 画面里所有人都要穿着得体，有人不合规马上停
5. **不用表演：** 按平常的方式干，不放慢、不讲解

前两天多去现场看看。看到手经常出画、镜头角度不对，当场纠正。

## 额度与设备轮换 {#rotation}

同一个场景、同一个买家能收的数据量有上限，录满了再录就不算有效时长。越简单的场景，饱和得越快。所以要准备尽可能多的场景，让设备不断轮换和铺开。

- 额度由 GI Labs 统一跟踪。哪个场景满了、哪家店需要换，会由对接人通知你
- 收到通知后尽快安排：换一个岗位，或者把设备挪到下一个场景、下一家店
- 换完记得重新扫码
- 和门店谈合作时就说清楚，设备会在不同岗位和员工之间轮换，一期做完会转到别处

**提前准备下一个场景。** 不要等通知来了才去找，设备闲一天就少一天的收入。

## 每日检查清单

### 开工（每台设备）

- [ ] 卡插好再开机，充电宝满电
- [ ] 连一次手机，同步时间。没连过的设备，录出来的日期会是 1970 年
- [ ] 设备页显示空闲，剩余空间够，固件是最新版
- [ ] 分辨率 1728×1200，手部检测开着（升级固件后重新检查）
- [ ] 扫对今天的"门店 × 操作员"码
- [ ] 调好角度，关掉预览，开始录制

实时预览只在调角度时打开，调好就关掉。

### 收工（上传负责人）

- [ ] 停止录制，拔卡，换上另一张卡
- [ ] 每张卡拷到电脑或移动硬盘，核对完整
- [ ] 开始上传，可以挂机过夜

### 第二天早上（上传负责人）

- [ ] 确认后台已经收到
- [ ] 清理电脑里的副本和 SD 卡
- [ ] 卡插回设备

### 每天（运营方）

- [ ] 看当天的验收结果，按反馈整改
- [ ] 按通知安排换场景或挪设备
- [ ] 新店、新人的资料收齐交给对接人
