# 和门店谈合作

## 去哪找店

| 渠道 | 做法 |
|---|---|
| 自己的熟人 | 先从认识的老板谈起，最容易成 |
| 行业聚集区 | 汽配城、维修一条街、服装加工区、餐饮街，一次能跑很多家 |
| 行业协会、商会 | 一次接触一批老板，也更容易建立信任 |
| 已合作门店介绍 | 老板之间互相介绍，成功率高 |
| 供应商、批发商 | 配件商、面料商、食材供应商认识大量门店 |
| 本地生活平台 | 在地图和点评平台上按类目筛店，再上门 |

先用 [金标准](/before/scenes#gold-standard) 筛一遍，三条都弱的不用去。

## 合作流程

1. **初访：** 介绍项目，看现场，了解有几个员工、各做什么活
2. **初判：** 回去对照金标准，看这家店有几个场景、能做多久
3. **试录：** 新场景先用一台设备试录 2 小时，等验收结果
4. **签约：** 试录通过后签 [门店合作协议](/business/templates/store-agreement)。员工 [同意书](/business/templates/operator-consent) 可以视情况签
5. **登记：** 收齐门店和操作员资料交给对接人
6. **铺设备：** 按 [收到设备时](/after/receiving-devices) 配置上岗
7. **结束一期：** 约定的周期做完，或活已饱和，设备转走。好好收尾，以后还能再合作，也能请老板介绍别的店

## 怎么开口

不要一上来就讲 AI 和机器人，先讲对老板有什么好处、对他的生意有没有影响。可以这样说：

> 我们在做一个项目，请手艺好的师傅戴一个小相机，正常干活就行，不耽误生意。录下来的视频是用来教机器人学手艺的。店里和戴设备的师傅都有报酬。先试两个小时，看看合不合适。

讲清楚三件事：

- **不耽误干活：** 师傅照常干，不用停下来讲解，不用表演
- **有报酬：** 店里和师傅都能拿到钱，怎么算当面说清楚
- **有边界：** 只录干活的部分，厕所、更衣室等私密区域不录

## 老板常问的问题

| 问题 | 怎么回答 |
|---|---|
| 录这个干什么用？ | 用来训练机器人和 AI 学习手上的活。录的是手和工具怎么动，不是拍人 |
| 会不会泄露我店里的东西？ | 数据加密上传，只用于模型训练，不公开发布。收款码、手机号、支付信息会尽量避开。具体写在合作协议里 |
| 会影响生意吗？ | 设备很轻，戴在头上，师傅照常干，不用停下来 |
| 员工愿意吗？ | 员工自愿参加，不愿意的不戴，随时可以不戴 |
| 给多少钱？ | 按你这边的报酬方式说清楚，写进协议 |
| 要录多久？ | 按一期谈，一般几周。期间设备在不同岗位、不同师傅之间轮换，做完转走 |
| 设备坏了算谁的？ | 正常使用的损耗不用店里负责。具体按协议 |
| 我要做什么？ | 提供门店资料，安排谁戴设备，给设备一个充电和存放的地方 |

## 谈判要点

### 按项目谈，不按天谈

每家店谈成"一期"：大概几周、覆盖哪些岗位、哪几个员工轮流戴。这样老板心里有数，你也方便安排设备轮换。

### 报酬方式提前想好

常见的三种：按有效时长分成、按录制时长给固定补贴、一期一次性合作费。见 [给门店和员工的报酬怎么定](/before/payment#site-pay)。

- 想让门店一起关心质量，用分成
- 老板嫌麻烦、只想要个确定的数，用固定补贴或一次性费用

### 说清楚会轮换

提前讲明白：同一个场景录到一定量就够了，设备会在不同岗位、不同员工之间换，一期做完会转到别处。不讲清楚，后面换设备时容易有矛盾。

### 不要承诺做不到的事

- 不承诺具体能录多少小时、拿多少钱，验收结果说了算
- 不承诺一定会续期
- 不承诺数据的具体用途和客户名称，按协议里的说法讲
- 不答应门店改设备设置、挑着录、安排人演

## 铺设备前要拿到

- 签好的门店合作协议
- 门店资料和操作员资料，见 [收到设备前](/after/before-devices)

## 合作期间维护好关系

- 每周跟老板碰一次，说说进展，听听有没有问题
- 按约定准时付钱
- 员工有意见及时处理
- 一期结束时好好收尾，问老板愿不愿意介绍别的店
