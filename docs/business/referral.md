# 推荐网络与推荐计划

设备会很快用掉手上的活，所以要一直有新店接上。最可靠的新店来源是已经合作过的人介绍。这一页分两部分：怎么建自己的推荐网络，以及 OpenRoboto 的推荐计划。

## 一、建自己的推荐网络

### 谁能帮你介绍

| 来源 | 能介绍什么 | 怎么请 |
|---|---|---|
| 合作过的门店老板 | 同行、上下游的店 | 一期结束时开口，合作顺利的成功率最高 |
| 戴过设备的师傅 | 以前的同事、师兄弟的店 | 平时聊天时问 |
| 配件商、批发商 | 他们的客户门店 | 给一点介绍费，或者帮他们带客户 |
| 行业协会、商会 | 一批会员门店 | 去做一次分享，讲清楚项目 |
| 其他运营方 | 不在你区域的店 | 互相交换，见下文推荐计划 |

### 怎么做

- **建一个店铺清单。** 记下每家店：介绍人、行业、员工数、有几个场景、谈到哪一步。可以用 [推荐登记表](/business/templates/referral-form) 的格式
- **给介绍人一点回报。** 介绍的店谈成并开录后，给介绍人一笔介绍费或一份礼物。金额由你自己定，写清楚、说到做到
- **介绍成了要告诉介绍人。** 让他知道自己的介绍有结果
- **口碑最重要。** 准时付钱、尊重员工、好好收尾，老板才愿意介绍朋友

## 二、OpenRoboto 推荐计划 {#program}

::: tip 说明
本计划为草案，下文中的空白处（____）为待定数字，以 OpenRoboto 正式公布的版本为准。
:::

### 推荐什么

| 推荐类型 | 推荐的是 | 适合谁 |
|---|---|---|
| 推荐运营方 | 一个新的运营方（个人或团队），在别的城市或区域开展采集 | 认识其他地方的门店资源方 |
| 推荐门店 | 一家你自己不方便做的门店，交给 OpenRoboto 或其他运营方去做 | 店在你的区域外，或你的设备排不过来 |

### 只算一层

推荐奖励**只算一层**：你推荐的人或门店产生的有效时长，算你的推荐奖励；他们再推荐的，不算你的。

### 怎么算推荐成功

| 推荐类型 | 成功条件 |
|---|---|
| 推荐运营方 | 被推荐方和 OpenRoboto 签约，且在签约后 ____ 天内累计有效时长达到 ____ 小时 |
| 推荐门店 | 门店签约并试录通过，且累计有效时长达到 ____ 小时 |

### 奖励

| 推荐类型 | 奖励方式 | 金额 |
|---|---|---|
| 推荐运营方 | 一次性奖励 | ____ 元 |
| | 加上被推荐方前 ____ 个月有效时长的分成 | 每有效小时 ____ 元，或结算金额的 ____% |
| 推荐门店 | 一次性奖励 | 每家 ____ 元 |

- 单个推荐人每月的推荐奖励上限：____ 元（如不设上限，删除此条）
- 奖励在被推荐方达到成功条件后的下一个结算周期发放

### 怎么推荐

1. 填写 [推荐登记表](/business/templates/referral-form)，发给对接人
2. 对接人确认被推荐方还没有被其他人登记过
3. 对接人和被推荐方联系、评估、签约
4. 达到成功条件后，奖励随结算发放

### 规则

- **先登记先算。** 同一个运营方或门店被多人推荐，以先登记、且经确认的为准
- **登记有效期：** 登记后 ____ 天内没有签约，登记失效，其他人可以重新推荐
- **不能推荐自己。** 自己另开主体、亲属代签等情况不算推荐
- **已经在合作的不算。** 已经和 OpenRoboto 或其他运营方合作的门店、已经签约的运营方，不能再被推荐
- **数据质量也算。** 被推荐方因数据质量问题被暂停或终止合作的，尚未发放的奖励不再发放
- **不能虚假推荐。** 编造门店、虚报信息的，取消推荐资格，已发奖励追回
- OpenRoboto 可以根据情况调整本计划，调整前会提前通知，已达成的推荐按原规则结算
