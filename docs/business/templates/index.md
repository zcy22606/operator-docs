# 协议模板

::: warning 使用前请先找律师审核
以下模板只是起草参考，不构成法律意见。各地对个人信息、肖像、劳动关系、数据出境的规定不同，签署前请让当地律师按实际情况修改。空白处（____）按实际情况填写。
:::

| 模板 | 谁和谁签 | 什么时候用 |
|---|---|---|
| [员工录制知情同意书](/business/templates/operator-consent) | 操作员本人（可选） | 需要时，在操作员第一次戴设备之前签 |
| [门店合作协议](/business/templates/store-agreement) | 运营方和门店 | 试录通过后、铺设备之前 |
| [设备交接单](/business/templates/device-handover) | 运营方和 OpenRoboto，或运营方和门店 | 收设备、交设备、换店时 |
| [推荐登记表](/business/templates/referral-form) | 推荐人填写 | 推荐新运营方或新门店时 |

## 使用要点

- **同意书是可选的**，不强制每人都签。门店或员工希望有书面约定时再用。要签的话，本人签字，不由老板代签
- **未满 16 周岁的人不能做操作员**。画面里尽量不要出现未成年人
- 员工不想再戴了，就换其他人，并告诉对接人
- 协议里的报酬条款要和你实际的付款方式一致
- 签好的文件拍照或扫描存档，按 [验收与结算](/after/acceptance#records) 的要求保存
