# 这份指南怎么用

OpenRoboto 和各地的运营方合作，在真实的经营场所里，让一线员工戴上头戴式相机，按平常的方式干活，录下第一视角的工作视频。这些数据用于训练机器人和具身智能模型。

运营方是这件事在当地的负责人：找门店、谈合作、管设备、带操作员，每天把数据传上来。

## 全流程

| 阶段 | 主要做什么 | 看哪一页 |
|---|---|---|
| 了解 | 看自己是否符合要求，评估手上的门店资源 | [要求、收益与注意事项](/before/requirements) |
| 选场景 | 判断哪些店、哪些岗位可以做，估算要准备多少 | [什么样的场景可以做](/before/scenes) |
| 算账 | 弄清收入怎么算，自己的成本怎么安排 | [收入怎么算](/before/payment) |
| 签约 | 和 OpenRoboto 签运营方协议，和门店签合作协议 | [和门店谈合作](/business/negotiation)、[协议模板](/business/templates/) |
| 准备 | 确认上传带宽，收齐门店和人员资料，配齐充电宝、SD 卡、手机、电脑 | [收到设备前](/after/before-devices) |
| 落地 | 验收设备，完成首次配置和试传 | [收到设备时](/after/receiving-devices) |
| 运营 | 每天录制、上传、轮换，看验收结果整改 | [日常运营](/after/daily-operations)、[数据上传 SOP](/after/upload) |
| 结算 | 按验收结果结算 | [验收与结算](/after/acceptance) |
| 扩张 | 开新店，推荐新的运营方 | [推荐网络与推荐计划](/business/referral) |

## 角色

| 角色 | 负责什么 |
|---|---|
| OpenRoboto 对接人 | 登记门店和操作员，发设备二维码，开上传子账号，同步验收结果和结算 |
| 运营方 | 谈店、签合同，培训操作员，管理设备，每天上传数据 |
| 门店负责人 | 提供门店资料，安排谁戴设备 |
| 操作员 | 戴设备，正常干活 |

一个运营方可以同时管多家门店。上传可以由运营方自己做，也可以指定一位"上传负责人"。

## 几个说法

| 说法 | 意思 |
|---|---|
| 门店 / 场地 | 一个实际的经营地点。连锁店的每家分店都算一个 |
| 操作员 | 戴设备干活的人，必须是这家店真正做这份工作的员工 |
| 场景 | 一类工作环境和工作内容，比如汽车维修、手机维修、中餐后厨。数据量和额度都按场景算 |
| 有效时长 | 经过验收、被认定为可用的录制时长，是结算的依据 |
| 对接人 | OpenRoboto 指派给你的联系人，所有问题都先找他 |

## 以哪份为准

设备操作和上传的细节，以 GI Labs 官方文档为准：[EGO1 使用文档](https://docs.gilabs.xyz/zh-Hans/docs/ego1)。本指南和官方文档不一致时，按官方文档做，并告诉对接人，我们会及时更新。

协议、单价和结算周期，以你和 OpenRoboto 签署的协议为准。
